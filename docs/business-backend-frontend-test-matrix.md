## 1. Nguyên Tắc & Điều Kiện Kiểm Chứng (Verification Protocol)

- **Unit / Component Tests:** Chạy độc lập trên môi trường Vitest / JSDOM với mocked responses và schema fixtures chuẩn để xác nhận logic UI, validation, định dạng tiền tệ và state transitions.
- **Integration Tests:** Yêu cầu chạy trên backend thật hoặc Local JAR có schema Flyway V38 khớp mã băm provenance, với tài khoản/tenant test đã ánh xạ chính xác `Employee` trong cơ sở dữ liệu.
- **End-to-End Tests:** Chạy trên trình duyệt thật (Playwright) xác nhận toàn bộ hành trình người dùng (User Journey), khẳng định UI gửi đúng request, backend phản hồi đúng dữ liệu và UI hiển thị đúng kết quả, quyền hạn và mã lỗi.
- **Tiêu chuẩn "Không có số nghĩa là không có số":** Không bao giờ giả lập 0 cho dữ liệu thiếu hoặc đang tính toán dở dang. Mọi trạng thái `UNAVAILABLE` phải hiển thị rõ lý do từ backend.
