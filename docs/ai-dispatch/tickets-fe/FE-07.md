# Ticket FE-07 — API client holder và cờ mock

- Nguồn ticket: mục `FE-07` trong `docs/ai-dispatch/05-fe-implementation-plan.md`.
- Loại: FRONTEND.
- Phụ thuộc: FE-05 (đã DONE).

## Mục tiêu

API module AI Dispatch dùng đúng Axios client đã tạo trong `App.tsx` (đã có token provider, refresh/replay, envelope), không tạo client thứ hai; thêm cờ môi trường `VITE_AI_DISPATCH_MOCK` mặc định `false`.

## File được phép tạo/sửa

- `src/lib/apiClient.ts` (mới)
- `src/lib/apiClient.test.ts` (mới)
- `src/App.tsx` (một điểm gọi setter)
- `src/config/env.ts`
- `.env.example`

## Các bước

1. Holder `setLogisticsApiClient` / `getLogisticsApiClient`; getter ném `AI_DISPATCH_API_CLIENT_NOT_READY` khi chưa có client; setter idempotent.
2. Gọi setter ngay sau `createApiClient` trong `RuntimeApplication`.
3. Schema boolean `VITE_AI_DISPATCH_MOCK` (`"true" | "false"`, default `"false"`), export `env.aiDispatchMock`.
4. `.env.example` ghi `VITE_AI_DISPATCH_MOCK=false`; không sửa `.env` cục bộ.

## Tiêu chí nghiệm thu

- Typecheck, lint, build đều exit 0.
- Test: getter ném lỗi trước khi set; set/get trả đúng instance; set lặp idempotent; set client mới thay client cũ; env default `false`, nhận `true`/`false`, từ chối giá trị khác.
- Không tạo `axios.create` mới, không đổi token provider, không log token.

## Ghi chú

- Cờ mock chỉ là cấu hình; theo FE-04/D12 không triển khai mock adapter cho endpoint AI thật.
- `src/lib/` được tạo mới trong ticket này.
